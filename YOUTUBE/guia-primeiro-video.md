# Guia Completo — Primeiro Vídeo (rachaduras)

Passo a passo executável. Metadados já gerados por scripts/gerar_metadados.py.

## PASSO 0 — Criar e configurar o canal (~30 min, 1x)
1. youtube.com logado → Criar um canal → nome editorial (evitar "ConstruData").
2. studio.youtube.com = o painel (é site, não download; app de celular opcional).
3. Config → Canal: País Brasil; keywords (construção, obra, reforma, rachadura, casa);
   "não voltado para crianças"; ativar dublagem automática, clipes, melhoria de vídeo/áudio.

## PASSO 1 — Metadados (prontos)
TÍTULO: O Que Cada Rachadura na Parede REALMENTE Significa (não ignore a nº 3)
DESCRIÇÃO: ver bloco no chat / regerar com scripts/gerar_metadados.py
TAGS: construcao, obra, engenharia civil, canteiro de obras, gestao de obras, rachadura,
      reforma, engenhariacivil, casa, tipos de rachadura

## PASSO 2 — Fliki (texto → vídeo)
- fliki.ai → New file → Text to video → Portuguese (Brazil) → escolher 1 voz (fixa).
- Colar os 6 blocos de narração (campo "narracao" de cada cena do roteiro).
- B-roll por cena: rachadura parede / massa corrida / trinca alvenaria /
  rachadura diagonal janela / muro de arrimo / gesso parede. Trocar clipes ruins.
- Legendas automáticas → gerar → baixar 1080p.

## PASSO 3 — Thumbnail
Claude Design ou Canva. Conceito 2: split fina(verde OK) x diagonal(vermelho ALERTA),
texto "PERIGO?". Fazer 2 versões pra teste de CTR.

## PASSO 4 — Shorts (auto-reframe 9:16)
02:45-03:35 · 04:20-05:00 · 00:30-01:15 (ganchos no roteiro/dia-de-teste-01.md).

## PASSO 5 — Publicar
Studio → Criar → Enviar vídeo → colar título/desc/tags → subir thumbnail →
"não é para crianças" → idioma PT → publicar. Subir os 3 Shorts com #Shorts.

Studio → Análises → exportar CSV → rodar /analise-semana → aplicar 3 ações no vídeo 2.
