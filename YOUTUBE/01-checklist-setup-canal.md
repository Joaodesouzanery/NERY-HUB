# Checklist — Setup do Canal (Construção)

> Faça na ordem. ~1–2h no total. Vale pro canal de Fazenda também (repita trocando o nicho).

## A. Criar o canal
- [ ] Criar canal de marca (Brand Account) na conta Google — **não** o canal pessoal.
      Isso permite ter vários canais e delegar acesso depois.
- [ ] Nome do canal: curto, memorável, ligado a obra/construção (ex.: "Obra Contada",
      "Canteiro", "Raio-X da Obra"). Evite nome de empresa (ConstruData) pra não parecer anúncio.
- [ ] Foto + banner simples (pode fazer no Canva/Figma depois).

## B. Configurações obrigatórias (Studio → Configurações)
- [ ] **Público:** "Não, definir este canal como não voltado para crianças" (nível do canal).
- [ ] **Conteúdo alterado/sintético:** só declarar por vídeo quando aplicável; não marcar canal inteiro.
- [ ] **Informações básicas → País de residência:** Brasil.
- [ ] **Palavras-chave do canal:** construção, obra, engenharia civil, canteiro de obras,
      gestão de obras, infraestrutura, história de obras (ajuste conforme subnicho).
- [ ] **Dublagem automática:** ativar "Permitir dublagem automática" (alcança outros idiomas de graça).
- [ ] **Clipes:** "Permitir que os espectadores criem clipes".
- [ ] **Qualidade:** ativar melhoria de vídeo e de áudio ("deixe o YouTube aprimorar").

## C. Identidade do conteúdo (defina antes de gravar)
- [ ] **Subnicho** (escolha UM): histórias de obras / engenharia explicada / gestão e erros
      caros / megaconstruções / infraestrutura brasileira.
- [ ] **Promessa do canal** em 1 frase (o que o inscrito ganha sempre).
- [ ] **Composição:** 60% história emocional · 25% caso real · 15% gestão/dados/tecnologia.
- [ ] **Formato visual de referência:** escolher 1 canal validado pra copiar o FORMATO
      (não o conteúdo) — registrar na planilha `02-analise-canais.csv`.

## D. Ferramentas (instalar/criar contas)
- [ ] Extensão **vidIQ** (grátis) no navegador.
- [ ] Conta **ElevenLabs** (plano ~US$5–22 conforme uso; escolher 1 voz PT-BR masculina/neutra padrão).
- [ ] **CapCut** (desktop) instalado.
- [ ] **Descript** (conta grátis pra começar).
- [ ] **MoneyPrinterTurbo** instalado (rascunhos) — opcional na semana 1.
- [ ] Pasta no **Google Drive** pra roteiros/thumbs (ou usar este repositório).

## E. Descrição padrão de vídeo (template)
```
{TÍTULO}

{Parágrafo de 3 frases cheio de palavras-chave — gerado pelo scripts/gerar_metadados.py}

▶ Se você curte histórias reais de obras e engenharia, inscreva-se.

#construcao #obra #engenhariacivil {mais 2-3 hashtags do tema}
```

## F. Antes de publicar o 1º vídeo
- [ ] Thumbnail: fazer **2 versões** pra testar.
- [ ] Título com palavra-chave + curiosidade (não clickbait vazio).
- [ ] Primeiros 30s do roteiro = gancho forte (a métrica que mais importa).
- [ ] Rodar `scripts/gerar_metadados.py` no roteiro pra sair título/desc/tags.
- [ ] Publicar/agendar. **Nunca** publicação 100% automática sem sua aprovação final.

Depois de publicar, siga `04-loop-otimizacao.md` toda semana.
