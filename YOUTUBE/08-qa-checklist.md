# QA Checklist — antes de publicar cada vídeo

> Rode esta lista rápida antes de todo upload. Pega os erros que derrubam CTR, retenção e monetização.

## Conteúdo
- [ ] Gancho nos primeiros 30s vai direto à tensão (nada de "hoje vou falar sobre").
- [ ] Cada afirmação técnica está correta (revisão de fato — evita "conteúdo inautêntico").
- [ ] Narrativa coerente: começo → tensão → desfecho/resumo.

## Fliki / visual
- [ ] Scene media = **Stock** (não AI images).
- [ ] Todo b-roll combina com a narração (nenhuma cena desconexa).
- [ ] Legenda bold e legível no celular.
- [ ] Mesma voz de sempre.
- [ ] Música de fundo baixa (YouTube licensed).

## Thumbnail
- [ ] 2 versões feitas (teste de CTR).
- [ ] Legível num quadrado pequeno (texto ≤ 4 palavras, contraste forte).
- [ ] Promete o que o vídeo entrega (curiosidade, não clickbait vazio).

## Metadados
- [ ] Título com palavra-chave + curiosidade (≤ ~70 caracteres visíveis).
- [ ] Descrição com keywords nas 2 primeiras linhas.
- [ ] Até 15 tags.
- [ ] Idioma do vídeo = Português.
- [ ] "Não é para crianças".

## Shorts
- [ ] 3 Shorts gerados (9:16), cada um com gancho próprio nos 1ºs 2s.
- [ ] #Shorts no título.

## Depois de publicar
- [ ] Anotar data. Voltar em 48h e 7 dias para as métricas → `/analise-semana`.

---

## Métricas-alvo (cola rápida)
| Métrica | Meta | Se ruim → ajuste |
|---|---|---|
| CTR | ≥ 4–6% | thumbnail/título |
| Retenção 30s | ≥ 70% | gancho |
| % assistido | ≥ 40% | ritmo |
| Inscritos/1.000 views | ≥ 3–5 | identidade |

Formato validado = CTR ≥5% + retenção ≥70% → fazer 3 variações.
