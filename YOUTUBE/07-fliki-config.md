# Configuração do Fliki — referência fixa (use sempre)

> Copie estas configurações toda vez. Elas foram calibradas para explainer de construção.
> REGRA #1: Scene media = STOCK, nunca AI images (rachadura de IA parece falsa = perde credibilidade).

## Plano
- Grátis gera só 1 min. Para vídeos de 4–6 min precisa do plano pago (Standard ~US$8–28/mês).

## LONG-FORM (vídeo principal 16:9)
| Campo | Valor |
|---|---|
| New file | **Script to video** |
| Format | **16:9 Landscape** |
| Template | **Start fresh** (No template) |
| Scene media | **Stock media** ✅ (NÃO "AI images") |
| Create scenes | **Sentences** |
| Narrator | **Portuguese (Brazil)** → Browse voices → voz masculina natural. Teste 2, FIXE 1 e use sempre. |
| Subtitles | **ON** → estilo **Boxed Blue** ou **Editorial Hero** (bold, alto contraste) |
| Extras | ✅ Highlight subtitles · ✅ YouTube licensed music · ✅ Generate on screen text · ✅ Add pauses between scenes · ❌ Generate sound effects |
| Visual guide tags | Homeowners in Brazil · Brazilian adults 30-50 · urban Brazil homes |

Depois de gerar: revise cena por cena. Onde o stock não combinar, troque o clipe (busque termos
melhores). Este é o único ponto de trabalho manual — vale 5–10 min.

## SHORTS (3 arquivos separados, 9:16) — sem edição
Para cada Short, crie um **arquivo Fliki novo**:
| Campo | Valor |
|---|---|
| Format | **9:16 Portrait** |
| Scene media | **Stock media** |
| Narrator | mesma voz do long-form |
| Subtitles | ON, bold (Word Focus ou Boxed Blue) |
| Script | colar SÓ a narração do trecho do Short (ver dia-de-teste-01.md → shorts_sugeridos) |

Assim você não corta nada — o Fliki gera o Short vertical direto do texto. 3 Shorts = 3 arquivos.

## Voz — nota
Fixe UMA voz e use em todos os vídeos (identidade do canal). Se a retenção travar, teste trocar a voz.
